## 3. องค์ความรู้สะสมจากการทดสอบ (QA Memory Candidates)

1. **จุดเปลี่ยนผ่านของ Zod 4**: ใน Zod 4 ออบเจกต์ `SafeParseError.error` จะไม่มี `.errors` array ให้ใช้ `issues?.[0]?.message || message` แทน
2. **ลำดับการตรวจสอบสิทธิ์ความปลอดภัย**: ใน API จัดการสมาชิก ต้องตรวจสอบสิทธิ์ของผู้เรียก (403 Forbidden) ก่อนการตรวจสอบกฎทางธุรกิจ (400 Bad Request) เพื่อป้องกันการเจาะสำรวจข้อมูล
3. **ข้อจำกัดของ PowerShell บน Windows**: ควรสั่งคำสั่ง npm/npx ผ่าน `cmd /c npm ...` เสมอเพื่อหลีกเลี่ยงข้อจำกัดของ PowerShell Execution Policy
